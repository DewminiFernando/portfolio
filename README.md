# 🌿 Cozy Sage Personal Portfolio

A clean, cozy, playful, soft sage-themed one-page personal portfolio website built with **React**, **Vite**, and **Tailwind CSS**. It is fully responsive, lightweight, and ready to be deployed on GitHub and Vercel.

## ✨ Features

- **One-Page Layout**: Smooth scrollable sections with sticky backdrop-blur navigation.
- **Custom Aesthetic**: Follows a cute, premium, soft sage-and-cream design theme with a playful "Comic Neue" typography system.
- **Infinite Skills Marquee**: A custom marquee skills ticker that loops seamlessly and pauses on hover.
- **Horizontal Project Cards**: Modern, wide cards displaying description, technologies, status badges, and interactive, handcrafted HTML/CSS browser-mockup previews.
- **State-Driven Contact Form**: Interactive inquiry form that shows a friendly validation success message without requiring a backend.
- **Responsive Design**: Stacks gracefully from massive desktop screens down to smaller mobile devices.
- **Lightweight**: Zero external heavy 3D or animation libraries, keeping load times near-instant.

## 🛠️ Tech Stack

- **Frontend Core**: React 19, JavaScript (ES6+), HTML5
- **Styling**: Tailwind CSS v4 (configured via direct theme mappings), CSS variables
- **Icons**: React Icons (Fa, Si sets)
- **Build Tool**: Vite 8

## 🚀 How to Run Locally

### 1. Clone the repository
```bash
git clone <github-link-placeholder>
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

## 📦 How to Build

To compile a production-ready optimized build bundle:
```bash
npm run build
```
The compiled files will be located in the `dist/` directory, ready to deploy.
